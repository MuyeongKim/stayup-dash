# STAY UP 12월 훈련 시연 순서 (2026-12-08)

노트북 한 대와 프로젝터(또는 TV) 한 대로 10분 동안 시연하는 순서입니다. **인터넷이 없어도 됩니다.** 노트북에는 기록자가 쓰는 **입력 화면**을, 프로젝터에는 지휘관이 보는 **현황 화면**을 띄웁니다. 연습 공간의 가상 실종 상황(완주군 소양면)을 그대로 씁니다.

## 전날 준비 (15분)

1. 시연 노트북에 v1.7.0 이상 ZIP을 풀고 `stayup-dash.html`을 **Chrome**으로 엽니다(더블클릭). 와이파이를 끈 상태에서도 열리는지 한 번 확인합니다.
2. 프로젝터를 연결하고 디스플레이 설정을 **확장**으로 둡니다. 프로젝터 해상도는 되도록 **1920×1080**으로 맞춥니다. 1280×720, 1024×768에서도 화면이 깨지지 않게 맞춰 두었지만 지도가 작아집니다.
3. 시작 화면에서 `예제로 연습하기 ↗`를 눌러 연습 공간을 열고, 아래 시연 순서를 끝까지 한 번 해 봅니다.

## 시연 5분 전

1. 연습 공간에서 `백업·설정` → `현재 상황을 예제로 바꾸기` → 확인을 누릅니다. 리허설 기록이 지워지고 예제가 **지금 시각 기준**으로 다시 채워집니다.
   - 예제의 열원감지는 30분이 지나면 `열원감지 확인 결과` 줄에서 사라집니다. 그래서 이 단추는 **시연 시작 10분 안**에 누릅니다.
2. 위쪽에 `순서 안내` 창이 보이면 `순서 안내 닫기`를 누릅니다.
3. `현황 화면 열기`를 누르고, 열린 창을 프로젝터 화면으로 끌어 놓습니다. 그 창을 한 번 누른 뒤 **`F`** 키로 전체 화면을 만듭니다.
4. 경보음이 필요하면 현황 화면의 `경보음 켜기`를 한 번 누릅니다(기본은 꺼짐).

## 시연 (10분)

| 순서 | 노트북에서 누를 것 | 프로젝터에 보이는 것 | 할 말 |
|---|---|---|---|
| ① 한눈에 (2분) | 누르지 않음 | 위 숫자 4개(골든타임 잔여 · 일출까지 · 비행 가능 판정 · 출동 경과), `지금 확인` 줄, 현재 우선 지시, 수색구역 지도, 드론 카드 | "지휘관은 이 화면만 봅니다. 빨강 ■이 먼저, 노랑 ▲이 다음입니다." |
| ② 지시 내리기 (1분) | `지시·상황 전달` → 새 문장 입력 → `현재 우선 지시로 올리기` | 큰 지시 문장과 `현재 우선 지시 · 19:49 지시`처럼 올린 시각 | "지시는 한 곳에서 바꾸면 모두에게 같은 문장이 보입니다." |
| ③ 무전 잔량 (1분) | `수색 기록` → `기체 빠른 갱신`의 1호기 칸에 `80` → Enter | 1호기의 빨간 `즉시 복귀`가 사라지고 `지금 확인` 줄에서도 빠짐 | "흐린 `추정 23`은 비행한 만큼 뺀 추정값입니다. 무전으로 들은 값을 넣으면 바로 바뀝니다." |
| ④ 열원 → 발견 (2분) | `수색 기록` 아래 `열원감지 확인 결과` 줄의 `대상자 발견 → 발견 기록` → Enter → 확인창에서 확인 | 맨 위 빨간 `발견` 띠, 지도 C3, 기록 맨 위 `발견` | "열원을 확인하면 한 번에 발견 경보까지 갑니다. 실수로 누르지 않게 한 번 더 묻습니다." |
| ⑤ 유인기 경보 (1분, 선택) | 판정 줄 오른쪽의 빨간 `⚠ 유인기 진입 (전 기체 즉시 착륙)` → 설명 → `유인기 경보 해제` | 전체 경보 띠, 판정 `■ 비행 불가`, 아직 떠 있는 기체 이름 | "헬기가 들어오면 버튼 하나로 전 기체 착륙 지시가 뜹니다." |
| ⑥ 질문 (3분) | 필요한 탭만 열어 보여 줌 | — | — |

발견 띠는 현황 화면의 `확인`을 누르면 내려갑니다.

## 시연 중 하지 말 것

- `새 수색 준비`는 누르지 않습니다. 연습 내용이 비워집니다. 눌렀다면 `백업·설정` → `현재 상황을 예제로 바꾸기`로 되돌립니다.
- 현황 화면 위에 마우스를 올려 두지 않습니다. 지도 위에 확대·축소 단추가 나타나 지도 윗줄을 가립니다. 마우스를 노트북 화면으로 옮기면 몇 초 뒤 사라집니다.

## 문제가 생기면

| 증상 | 할 일 |
|---|---|
| 프로젝터 화면이 안 바뀜 | 입력 화면 오른쪽 위가 `현황 화면 연결됨`인지 봅니다. 아니면 현황 창을 닫고 `현황 화면 열기`를 다시 누릅니다. |
| 화면 아래가 잘림 | 현황 창이 전체 화면인지 봅니다(`F`). 프로젝터 해상도를 1920×1080으로 올립니다. |
| 글자가 작음 | 현황 화면을 한 번 누르고 `+` 키(작게는 `-`). |
| 순서가 꼬임 | `백업·설정` → `현재 상황을 예제로 바꾸기` 후 ①부터 다시 합니다. |

# 자동 기상 조회의 즉시 연결과 상태 안내

## 범위와 기준

기존 Open-Meteo 조회 함수·10분 주기·저장 형식과 안전 확인 기준을 유지한다. 사용자가 요청한 현장 좌표 확인 직후 조회, 인터넷 재연결 시 조회, 조회 중·수신 시각·연결 끊김·실패 안내를 추가한다. 기존 UI와 `refero-design`의 상태·다음 행동 중심 문구를 기준으로 안전 확인 단계에 안내를 둔다.

- 자동 조회는 자동 갱신을 켠 입력권 소유 창에서, 실제 작업의 확인된 좌표에만 수행한다.
- 연습·보기 전용·자동 갱신 끔·확정된 수동 관측값 보호 조건은 유지한다.
- 입력 중인 수동 값, 좌표 변경, 연결 끊김, 상황 교체·삭제·입력권 변경 시 진행 중 응답이 옛 값을 덮지 않게 한다.
- 자료 기준 시각과 조회 시도 시각은 기존 필드로 표시한다. 이 창의 마지막 수신 시각은 보기 상태로만 보관하며 백업 형식에 필드를 추가하지 않는다.
- 자동 수신을 현장 확인 완료나 비행승인으로 처리하지 않는다. 기존 변화 감지·재확인·30분 만료 기준을 그대로 적용한다.

## 검증 목록

| 작업 | 확인 |
| --- | --- |
| 시작·좌표 미확인 | 요청하지 않고 필요한 입력 위치 안내 |
| 좌표 확인·자동 갱신 켜기 | 즉시 한 번 조회, 진행 상태·수신·기준 시각 표시 |
| 실제 브라우저 연결 끊김·복구 | 기존 값 보존, 재연결 뒤 자동 조회 |
| 수동 입력·확정 수동 값·자동 갱신 끔 | 값을 보호하고 의도하지 않은 요청 없음 |
| 수동 지금 갱신·재시도 | 기존 교체 확인 절차와 실제 요청·결과 확인 |
| 지연된 응답·좌표 변경·상황 교체 | 이전 응답이 최신 입력·새 상황을 덮지 않음 |
| 연결 실패·잘못된 응답·시간 초과 | 실패와 재시도 경로, 기존 자료 보존, 조회 중 고착 없음 |
| 보기 전용·연습 | 외부 요청·편집권·실제 기록 간섭 없음 |
| PC·320/390px·주야간·재시작·백업 | 가독성과 자료·저장 형식·안전 경계 유지 |

가상 자료와 임시 Chrome을 사용하며 실제 초보 직원 관찰 또는 현장 계측 검증으로 표현하지 않는다.

## 검증 결과

- 자동 기상 실제 Chrome 검사: HTTP·파일 직접 실행 각각 **33/33**. 네트워크 연결 전환, 실제 12초 제한, 잘못된 응답, 지연된 이전 위치 응답, 조회 중 정상/오류 수동 입력, 확정 수동 값 보호와 명시적 교체 확인을 검증했다.
- 수신 중 다른 대상자 정보를 입력하고, 전체 백업을 실제로 내려받아 날씨 외 업무 값·사진·기록이 유지되는 것을 비교했다. 수신 시각 보기 상태가 JSON 키로 추가되지 않음을 확인했다. 자동 갱신을 끈 일회 조회도 설정을 임의로 켜지 않고 수신 사실을 표시했다.
- 공개 시험 좌표로 파일 직접 실행에서 실제 기존 기상 제공처의 기온·풍속·돌풍 자료 수신을 확인했다. 기상 확인과 비행승인은 자동 완료되지 않았다. 실제 출동 자료를 사용하지 않았고, 연결 성공을 현장 실측 정확도나 상시 가용성으로 표현하지 않는다.
- v1.2.42 자료 업그레이드·화면·AI 대응 메모 **101/101**, 기존 전체 회귀 **411/411**, 파일 직접 실행의 사용성·백업·복구·실제/연습 분리 **58/58** 통과. 네트워크 이벤트 변경 후에도 실제 브라우저·서버 종료를 거친 오프라인 재시작 **20/20**을 통과했다.
- 설명서의 기상 절차와 상태·시각 화면 예시를 갱신한다. 예시 이미지는 가상 응답을 사용했다고 명시한다.

실행 증거는 `/tmp/stayup-weather-auto-20261026/`에 보관한다. `release-http`·`release-file`의 결과와 기상 포함 실제 가상 백업, `final-layout`의 업그레이드·전체 회귀, `live-provider-check.json`의 공개 시험 연결 결과를 포함한다. 새 위치·네트워크 조건이 맞지 않으면 기존처럼 자동 조회하지 않으며 현장 판단 경계를 유지한다.

# 실제 사용 동선 1~5 개선

## 기준과 설계 결정

v1.2.41을 임시 Chrome과 가상 자료로 실행한 검토 결과를 반영한다. 기존 밝은 입력 화면·파란 선택 표시·주황 주요 동작과 안전 경보의 의미를 유지한다. Refero 도구가 없어 `refero-design`의 행동 중심 문구·점진적 정보 표시 원칙과 실제 검토 화면을 기준으로 삼는다.

| 항목 | 구현 범위 | 보존 조건 |
| --- | --- | --- |
| 1. 새 수색 시작 | 작업 화면 상단에 기존 새 수색 동작을 바로 제공 | 백업 다운로드·파일 보관 확인·복구본 생성·취소 절차 유지 |
| 2. 현재 단계 이동 | 빈 우선 지시는 한 줄로 축소. 안내를 켜면 선택한 입력 제목 아래에도 이전·다음 제공 | 실제 지시 전문·연락·안전 판정·경보 유지. 새 고정 영역으로 입력을 덮지 않음 |
| 3. 지도 준비 | 현재 실행 환경의 제한과 지금 가능한 사진 지도 선택을 먼저 안내. 준비 방법·설명서 연결 | 지도·범위·핀·기록 보존, 웹 주소 필요 조건과 무결성 검사 유지 |
| 4. 기체와 배터리 | 기체별 교체 순서·재고로 이동·해당 기체로 복귀. 미지정 조종자·미확인 잔량 강조 | 재고·잔량·상태를 실제 확인 후 각각 반영. 자동 차감·100% 설정·준비 완료 추정 없음 |
| 5. 백업 구분 | 상황 별칭과 초 단위 시각이 있는 파일명, 요청한 파일명을 화면에 표시 | JSON·사진·저장 형식 유지. 기존 파일과 지정한 자동 백업 파일은 바꾸지 않음 |

## 검증 목록

- 기존 상황 재시작→상단 새 수색→취소, 실제 백업 다운로드→보관 확인 취소, 정상 새 수색 전환.
- PC·320/390px·짧은 화면에서 단계 이동, 빈/입력한 우선 지시, 전문 열기·접기, 실제 경보·안전 판정 노출.
- 파일 직접 실행의 사진 선택·취소와 지도 준비 안내. HTTP의 지역 지도 저장·재시작은 기존 검사로 확인.
- 두 기체 중 선택한 기체의 교체 재고 안내→해당 잔량으로 복귀. 메뉴 이동만으로 자료·재고·이력 불변.
- 재고 수량 이동·기체 잔량·기체 상태의 기존 독립 동작, 미확인/확인된 기체 표시, 보기 전용 보호.
- 한글·특수문자·긴 상황명·빈 상황명의 실제 다운로드 파일명과 화면 안내. 전체 파일 값 비교·다시 열기·자동 백업 기본 이름.
- 기존 v1.2.41 자료·사진·구역·인원·기체·활동·AI 대응 메모의 업그레이드 보존과 전체 회귀 검사.

실제 사용자 프로필·출동 자료를 사용하지 않는다. 도구 기반 실행 검토이며 직원 관찰 평가·Windows 물리 장비 검증으로 표현하지 않는다.

## 결과와 실행 증거

- 새 동선 검사: HTTP **34/34**, 파일 직접 실행 **35/35**. 새 수색의 첫 취소·백업 후 확인 취소·정상 전환·복구본 보존, 기체별 재고 왕복, 보기 전용, 한글·특수문자·긴/빈 상황명의 실제 다운로드, 자동 백업 이름, 전체 자료·사진 복원을 확인했다.
- 기존 준비→백업 파일 실행 **35/35**, 배터리·기체 파일 실행 **33/33**, 사용성·실제/연습 분리 HTTP **58/58** 통과.
- v1.2.41 자료·사진·구역·인원·기체·기록·AI 메모 업그레이드와 화면 **101/101**, 기존 전체 회귀 **411/411** 통과.
- 오프라인 브라우저 **20/20**. 실제 브라우저와 HTTP 서버를 종료한 뒤 인터넷 없이 앱·타일·지도·핀·구역이 다시 표시되는 기존 검사를 통과했다. 외부 지도 사업자의 인증키·유료 요청은 사용하지 않았다.
- 빈 지시의 모바일 상단 공통 영역은 검토 화면의 약 299px에서 약 234px로 줄었다. 이전·다음은 입력 제목 아래와 끝에서 사용하며, 추가 고정 바는 만들지 않았다. 실제 입력 지시·전문·연락·경보는 유지한다.
- 실제 마우스로 사진 지도의 C2→C3를 쓸어 두 칸의 완료와 한 건의 이력을 확인하고, 직전 쓸기 취소로 원래 구역과 취소 이력이 남는 것을 확인했다.

처음 전체 회귀에서는 온라인 지도 칠하기 네 항목이 실패했다. 안내와 팔레트가 펼쳐지며 검사 좌표가 iframe 높이 900px 밖(약 924px)으로 내려가 `elementFromPoint`가 대상을 찾지 못했다. 테스트를 실제 사용처럼 지도를 보이는 위치로 스크롤한 뒤 입력하도록 수정했고, D2·D3 완료·한 건의 기록·되돌리기 조건을 그대로 유지했다. 네이버·구글 모의 지도 24항목과 전체 411항목을 다시 통과했다. 제품의 칠하기 로직·좌표 변환·기록 조건은 바꾸지 않았다.

검증 원본은 `/tmp/stayup-operator-flow-20261026/`에 보관한다. `final-flow-http`·`final-flow-file`·`final-layout`·`offline`의 결과, `actual-pointer-map.json`, 가상 수동/자동 백업과 화면 예시를 포함한다. 설명서 MD·HTML·PDF와 새 수색·단계 이동·배터리·지도 환경·실제 파일명 예시도 갱신한다. 실제 초보 직원 관찰과 Windows·물리 휴대폰 인수시험은 별도다.

마지막 점검에서는 연습 백업의 실제 파일명과 실패 안내에도 `연습-`을 유지하는지 확인했다(`practice-filename-check.json`). 최종 소스로 업그레이드·화면 101/101과 전체 회귀 411/411을 다시 통과했다(`release-layout`). 설명서는 31쪽으로 생성해 렌더링했으며, 단독 그림·한 문단만 남던 시작 부분의 쪽 배치를 정리했다.

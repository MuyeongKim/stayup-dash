# 지도 중심 상황판 보완 (2026-11-15)

사용자 요청: "상황판이니까 지도 부분이 부각되어야 하고 사용성이 좋아야 해. 지도에서 선 긋기, 범위 설정 등이 되어야 하고 아이콘들(이동경로, 사람, 드론, 차 등)이 표시가 원활히 되었으면 해." 같은 작업에서 화면 꾸밈도 함께 다듬었습니다.

## 바뀐 것

| 영역 | 전 | 후 |
| --- | --- | --- |
| 선 긋기 | 없음 | `이동 경로`(파란 실선·끝 화살표), `수색 동선`(초록 점선), `통제선`(굵은 빨간 점선). 점을 찍고 끌어 고치며 길이를 보여 줌. 최대 40개·선당 64점 |
| 범위 | 다각형 자유 구역만, 설정 접힘 안쪽에 숨어 있음 | 지도 아래 도구에 `다각형 범위`·`원 범위`. 원은 중심을 누른 채 끌어 반경을 정하고 24각형 자유 구역으로 저장(상태·담당·이력 그대로) |
| 표식 | 차량·펌프차·구급차·지휘차·드론 5종, 회색 사각 | 지상팀·수색견·구조대·집결지(CP) 추가 9종. 사람(주황 원)·장소(보라)·기체(파랑 원)·차량(남색)으로 색이 갈림 |
| 표식 옮기기 | 정보 창 → `위치 옮기기` → 지도 클릭 | 지도에서 바로 끌어 옮김. 끌지 않고 누르면 정보 창 |
| 겹침 | 구역·선이 표식 위에 그려져 이름표를 가림 | 구역 < 선 < 표식 < 최종목격·발견 핀 순서 |
| 지도 사진 없을 때 | 표식을 놓을 수 없음 | `지도 없이 격자로 시작` 뒤에도 표식·선·범위 사용 |
| 벽 화면 지도 면적(1920×1080) | 26% | 33%: 안전·기상 카드를 한 줄 띠로(값은 자르지 않음, 인접기관은 두 줄까지), 진행률·범례 한 줄, 양옆 열 조금 좁힘 |
| 벽 화면 지도 면적(1366×768) | 23% | 24%: 좁은 화면에서는 안전 띠가 두 줄로 접혀 잘림 없이 보이는 쪽을 택함 |
| 입력 화면 지도 탭 | 지도 위 도구 330px에 밀려 지도가 첫 화면 아래 | 그리기 도구를 지도 아래로 옮기고 지도 위 `선·범위·표식 ↓` 바로가기. 지도가 첫 화면 안에서 시작 |
| 입력 화면 맨 위 막대(1366) | 세 줄(`현황 화면 열기`만 둘째 줄) | 두 줄: 저장·연결 상태를 숫자 줄 오른쪽으로 |
| 휴대폰에서 그리기 | (새 기능) | 그리기 막대가 지도 아래쪽을 덮어 점이 안 찍히던 것을 고쳐 화면 아래 메뉴 위에 띄움. 그리는 동안 손가락 끌기를 화면 스크롤이 빼앗지 않음(390×844 터치 흉내로 탭 3번·점 끌기·원 범위 확인) |
| 입력 화면 우선 지시 카드 | 현장 상황 공유가 있으면 `상세 보기`가 혼자 아랫줄 왼쪽으로 떨어짐 | 첫 줄 오른쪽에 고정 |
| 브라우저 기본 표면 | 기본 파란 선택색·두꺼운 스크롤 막대 | 주황 선택색, 주황 입력 커서, 얇은 스크롤 막대 |

선은 지도 원본 비율 좌표(0~1)로 저장해 사진·저장 지도·온라인 지도와 벽 화면에 같은 자리로 그립니다. 상황 JSON 백업에 포함되고, 지도·수색 범위 교체 때는 `변경 전 구역 이력`에 보존합니다. 구버전 백업(선 없음)은 그대로 열리고 잘못된 선 자료는 버립니다.

## 남겨 둔 것

- 꾸밈 검사 도구가 알려 준 기존 디자인 요소(카드 왼쪽 색 띠 10곳, 바뀐 칸 강조 빛, 배터리 막대 폭 전환, 상단 흐르는 글자)는 원래 디자인이라 바꾸지 않았습니다.
- 이동 경로의 시간 기록(언제 어디를 지났는지)은 넣지 않았습니다. 지금은 손으로 그리는 선입니다.
- 1366×768 벽 화면 지도 면적은 거의 그대로입니다. 더 넓히려면 상단 숫자 카드 높이를 줄여야 합니다.

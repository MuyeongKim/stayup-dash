# 지도 위치 고정과 장비 배치 검토

## 구현 기준

- 대상: 처음 사용하는 직원이 네이버지도 위치를 맞추고 고정한 뒤 장비를 배치한다.
- 기존 수색 범위·핀·구역·자유 구역·활동기록·기체 상태·사진을 보존한다. 화면 고정은 수색 범위 변경과 구분한다.
- 기준 화면: 기존 STAY UP v1.3.0 수색 지도. `/tmp/stayup-map-before.png`에서 현재 조작·밀도 확인.
- Refero 도구가 없는 환경에서 번들 `icons.md`, `copywriting.md`, `craft-details.md`를 참고했다. 기존 색·버튼·접기·상태 안내를 유지하고, 동일 선 두께 SVG와 문자 라벨, 상태→다음 행동 안내, 키보드·44px 터치 영역을 적용한다.
- 외부 지도 실키 연결은 실제 성공 여부와 SDK 모형 검증을 구분한다. 실제 위치 추적 기능으로 표현하지 않는다.

## 확인 목록

1. 네이버 미리보기: 연결 조건·실행 환경·키 오류, 위치 이동·확대·축소, 기존 범위로 복귀, 확정·취소.
2. 화면 고정: 재열기·표출, 고정 중 이동 입력 차단, 해제 후 이동, 기존 수색 범위·기록 보존.
3. 장비: 종류→명칭/기체 선택→지도 클릭, 키보드 배치, 상세·명칭 수정·이동·배치 해제·취소.
4. 드론: 기존 등록 ID 연결, 조종팀/기체 보고 위치 구분, 상태·배터리 보존, 연결 기체 삭제 시 위치 보존·연결 없음 안내.
5. 보존: JSON 다운로드·가져오기·재시작·복구·표출 동기화·실제/연습 분리·잠금 중 장비 배치.
6. 경계: 미준비 지도·범위 밖·오염된 가져오기·편집권 변경·구역 초안 충돌·저장 실패.
7. 화면: 주간/야간, 320/390px·노트북·대형 표출. 아이콘·이름·상태·취소 버튼 가림과 넘침 확인.

## 결과

- 네이버 위치 맞추기 미리보기와 화면 고정·해제를 추가했다. 기존 범위가 있으면 화면 중심·확대만 바꾸며 구역·핀·사진·기록을 유지한다. 빈 지도만 확인 후 최초 범위를 설정한다. 좌표 없는 사진·표식은 보정을 먼저 안내한다.
- 차량·펌프차·구급차·지휘차·드론 SVG와 이름을 지도에 배치한다. 상세에서 수정·이동·배치 해제를 수행한다. 드론은 등록 기체와 연결하고 조종팀/기체 보고 위치를 구분한다. 배터리·운용 상태는 자동 변경하지 않는다.
- 장비 배열은 현재 지도 및 과거 구역 이력의 정규화·백업·복구·표출 경로에 포함한다. 격자 변경 시 위치를 유지하고 다른 사진/범위 교체 시 당시 이력에 보존한다. 기존 v4 저장공간과 업무 필드를 유지한다.
- 작은 화면의 이름표 겹침을 줄이고 최종목격·발견 핀을 우선 표시한다. 화면 밖 장비의 이름표가 지도 안에 떠서 보이던 현상을 수정했다. 같은 위치의 여러 장비는 배치 목록으로도 찾을 수 있다.
- 큰 지도에서는 장비 도구를 접어 지도 공간을 확보하고 닫으면 원래 펼침 상태로 되돌린다. 네이버 연결 성공 후 최초 키 설정을 접고 다음 행동인 위치 맞추기를 보여준다.
- 현황 창을 연 700ms 뒤 직접 입력 화면을 재구성하던 기존 경로가 드래그 중 포인터 캡처를 끊는 문제를 재현했다. 기존의 포인터 해제 대기 갱신 경로를 사용하도록 보완했다.

## 확인 범위와 남은 사항

- 실제 NAVER Client ID·등록 도메인·지도 타일·계정 요금은 검증하지 않았다. 첫 연결 시 담당자의 Web Dynamic Map 활성화와 웹 주소 등록이 필요하다. 모형 검사를 실서비스 연결 성공으로 표현하지 않는다.
- 화면 크기와 키보드·포인터 조작은 Chrome으로 확인했다. 실제 직원 사용성 평가나 Windows·물리 휴대폰·현장 위치 정확도 인수시험은 별도다.
- 동일 지점의 여러 표식은 실제 위치를 임의로 옮기지 않으므로 겹칠 수 있다. 확대·배치 목록에서 이름을 확인한다.
- 이전 앱은 새 장비 필드를 알지 못한다. 업데이트 후 이전 입력·현황 창을 닫고 최신판에서 편집한다.

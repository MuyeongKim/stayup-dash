# 벽 상황판 보완 (2026-11-10)

현황 화면을 "멀리서 읽고 손대지 않는 벽 화면"으로 점검하고 보완했습니다. 업무 자료(상황·구역·기체·기록)의 저장 형식과 값은 바꾸지 않았습니다.

## 점검에서 찾은 문제

| 문제 | 측정 | 조치 |
| --- | --- | --- |
| 주간 테마의 중요 기록 줄(발견·열원·지시·안전사고) 글자가 배경과 같은 색 | 대비 1.1~1.2:1 | 밝은 바탕·짙은 글자·왼쪽 색띠, 4.5:1 이상 |
| 주간 테마의 기체 비행시간·잔여추정·담당구역·고도 | 대비 1.4:1 | 밝은 칸·짙은 글자 |
| 현재 우선 지시가 맨 아래 작은 글자 | 15~16px | 상단 숫자 바로 아래, 1920×1080에서 약 30px(최대 두 줄) |
| 지도가 화면의 일부만 차지 | 화면의 21% | 조작 단추를 지도 위에 띄우고 4초 뒤 숨김, 진행률 한 줄 배치 → 27% |
| 3번째 기체·지난 기록이 카드 아래에 숨음(벽 화면에서는 아무도 스크롤하지 않음) | — | 넘치는 목록을 스스로 쪽 넘김(첫 쪽 16초, 나머지 8초), `1/3 쪽` 표시 |
| 높이 900px 이하 화면은 열 전체를 스크롤하는 배치 → 타임라인이 화면 밖 | 1366×768에서 타임라인 미표시 | 열 스크롤 대신 카드별 고정 비율 + 쪽 넘김 |
| 유인기 경보 띠가 본문을 밀어 출동 인원·특이사항·기체가 잘림 | — | 경보 중 상단 숫자 축소, 모든 카드 화면 안 유지 |
| 최종목격 핀 이름표가 같은 칸의 구역명·담당을 가림 | — | 핀이 놓인 칸의 구역명을 핀 반대쪽 모서리로 이동 |
| 안전 항목 값이 좁은 칸에서 `진입…`처럼 잘림 | — | 이름과 값을 한 줄에 두되 넘치면 다음 줄로 |

함께 고친 입력 화면 문제(사용검증 중 발견):

- 마우스로 구역을 칠하다 `Esc`를 누르면 칠하기만 취소되지 않고 큰 지도 전체가 닫혔습니다. 이제 칠하기·지도 이동 중의 `Esc`는 그 동작만 취소합니다.
- 지도 교체 확인창에서 `취소`를 누르면 "지도 이미지를 처리하는 중…"이 계속 남았습니다. 이제 "지도 교체를 취소했습니다. 기존 지도와 기록은 그대로입니다."를 표시합니다.

## 새로 더한 것

- **바뀐 것 강조:** 현황 창을 연 뒤 상태가 바뀐 칸(1분)과 새 기록(1분 30초)을 테두리와 `새` 표시로 강조합니다. 처음 연 순간의 내용은 표시하지 않습니다. 새 기록이 들어오면 기록 목록을 첫 쪽으로 돌립니다.
- **입력 갱신 시각:** 시계 아래 `입력 갱신 HH:MM · N분 전`. 15분 이상 변화가 없으면 주의 색(경보 아님).
- **교대·보고용 한 장 요약:** `백업·설정`에서 새 창으로 열고 A4 한 장으로 인쇄·PDF 저장. 상단 숫자는 현황 화면과 같은 계산을 씁니다.
- **수색 진행 다시 보기:** `수색 기록`에서 구역 완료·정정 기록을 시간순 재생. 수색중 표시만 바꾼 칸은 기록이 없어 나오지 않습니다.

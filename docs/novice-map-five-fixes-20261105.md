# 처음 사용자 지도 흐름 5개 보완

## 범위와 기준

- v1.4.0의 독립 브라우저 감사에서 재현한 5개 문제를 보완한다. 사용자 요청에 따라 터치 후 자동 정보창과 보이지 않는 실패 안내를 먼저 수정한다.
- 기준 화면은 `/tmp/stayup-user-review-20261105/`의 첫 지도·모바일 터치·연결 실패·320px 큰 지도 캡처다. 기존 STAY UP 디자인과 Refero 번들 `copywriting.md`·`craft-details.md`의 다음 행동/인접 피드백/포커스 원칙을 적용한다.
- 변경 대상은 조작 이벤트와 보기 구성이다. 기존 v4 저장 형식·입력·사진·기체·인원·장비·구역·이력·기록·안전 판단을 유지한다.
- 실제 사용자 브라우저를 사용하지 않고 별도 Chrome 컨텍스트·가상 자료로 확인한다. 브라우저 역할 수행 검증과 실제 직원 사용성 평가를 구분한다. 실제 NAVER 인증키·타일 접속 성공으로 표현하지 않는다.

## 확인 목록

1. 390/320px 실제 터치 배치 후 지도 유지, 바로 다음 의도적인 표식 터치는 정상 상세 열기. 배치·이동·취소·키보드·마우스 동작 보존.
2. 지도 미준비·잘못된 키·SDK 실패와 진행 상태를 누른 버튼 근처에서 확인. 입력값·초점 유지와 재시도.
3. 빈 지도는 사진/온라인/저장 지도 선택부터 시작. 준비 후 현재 지도와 다음 행동을 표시. 보기 선택만으로 자료를 변경하지 않음.
4. file 실행→사진 사용/웹 실행 안내, 미보정 사진→실제 좌표 보정 위치 바로가기. 취소·복귀와 자료 유지.
5. 320/390px 큰 지도에서 지도 공간 확보, 도구 열기/닫기에도 지도 위치·배율·표식 유지. 긴급·저장 알림과 지도 닫기 유지.
6. v1.4.0 기존 자료 재열기, 실제 JSON 다운로드·복원, 표출·연습 분리, 기존 회귀·오프라인 실행.

## 검증 기록

### 보완 결과

- 터치 배치·이동을 끝낸 같은 제스처의 후속 클릭만 소비한다. 다음에 의도적으로 누른 표식은 바로 상세 정보를 연다. 키보드·마우스·기체 상태와 저장 구조는 유지한다.
- 지도 미준비 안내를 누른 도구 근처에, 연결 진행·실패를 연결 버튼 아래에 표시한다. 오류 안내와 연결 버튼을 함께 노출하며 초점·입력값을 보존한다.
- 빈 지도는 사진·온라인·저장 지도 세 선택부터 시작한다. 준비 후 현재 지도와 지도 바꾸기로 축소하고, 온라인 선택 시에만 네이버 위치 맞추기를 보여준다. 다른 지도·캡처 설정은 추가 지도 설정에서 유지한다.
- 파일 실행은 사진 사용/웹 실행 방법으로, 미보정 사진은 실제 좌표 보정 입력 위치로 바로 이어진다. 조회·이동·취소만으로 업무 상태를 바꾸지 않는다.
- 큰 지도의 확대·축소·전체 맞춤은 항상 접근할 수 있다. 나머지 편집·장비 도구는 내부 스크롤 패널로 열며 모바일 높이는 35vh 이내다. 320×800에서 지도 영역 약 607px을 확보했고 도구를 열어도 크기·카메라를 유지했다. 가로 사진은 전체 맞춤에서 여백이 생길 수 있으므로 실제 확대·이동도 검증했다.

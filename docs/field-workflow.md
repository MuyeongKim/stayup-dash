# 결과 전달·지도 좌표·사용자 구역 편집

2026-10-27 · 사용자 승인에 따른 1~3단계 구현.

## 처음 여는 순서와 기존 자료

1. 기존 입력·현황 창을 모두 닫고 새 버전으로 엽니다.
2. 이전 상황이 있으면 **상황·복구본·지도·탐지 사진을 별도 저장공간으로 복사하고 바이트를 검증**합니다. 원래 자료는 삭제하지 않습니다. 기존 창이 편집 중이거나 복사·저장 확인에 실패하면 새 편집을 시작하지 않습니다. 안내를 해결한 뒤 새로고침해 다시 시도합니다.
3. 상황명·지도·탐지 사진·대응 기록을 확인하고 새 버전의 현황 창을 다시 엽니다. 구버전 현황 창은 새 저장공간을 따라오지 않습니다.
4. 기존 버전 1~3의 완전한 JSON 백업도 불러올 수 있습니다. 새 구역 정보가 있는 형식 4 백업은 보완판에서 엽니다.

실제 저장 키는 `stayup.dash4.*`, 사진·탐지 이미지 DB는 `stayup.dash.v4`입니다. 연습 공간은 `stayup.practice4.*`와 `stayup.practice.v4`로 분리합니다. 기존 저장 키·DB와 사용자 파일을 지우지 않으며, 준비한 지역 지도 카탈로그는 기존 지도 엔진에서 계속 사용합니다. 단, 사용자가 백업 보관을 확인하고 **완전삭제**를 입력한 종료 절차는 이전 버전 이관 원본까지 삭제합니다. 새 버전의 복구본과 구역 이력에 필요한 이미지도 일반 자동 정리에서 보호합니다.

이 저장 방식 변경과 격자 변경 전 이력 보존은 2026-10-27 사용자 확인 후 적용했습니다.

## 전달사항을 바로 표출하기

- 상단 **전달사항 작성**에서 `현장 상황 공유` 또는 `현재 우선 지시`를 선택합니다.
- 상황 공유는 240자, 우선 지시는 기존 80자입니다. **입력 중인 초안은 보내지 않으며 표출을 눌러야** 두 창에 반영됩니다.
- 상황 공유는 지시와 별도 줄에 표출 시각과 함께 나옵니다. 기존 지휘부 지시 전문과 연락 정보는 유지합니다.
- 내용 변경·해제는 활동기록에 남고 저장 실패 시 원문과 초안을 유지합니다. 읽기 전용 창은 표출할 수 없습니다.
- 작성·좌표 선택창에서도 비행 판정과 유인기·발견 경보를 표시합니다. 창을 닫는 것은 경보 확인·해제가 아닙니다.

## 현장 기준 좌표 선택하기

**상황 입력 → 지도에서 좌표 선택·붙여넣기**를 누릅니다.

- 위도·경도 두 숫자를 쉼표 또는 공백으로 구분해 붙여넣을 수 있습니다.
- 기존 설정에 구글·네이버 키가 있으면 종류를 고르고 **선택 지도 연결**을 누릅니다. 새 계정이나 결제 설정을 만들지 않지만 온라인 지도 사용량은 해당 계정에 발생할 수 있습니다.
- 현재 연결된 저장 지역 지도가 있으면 해당 지도로 선택합니다. 준비한 지도 범위 안에서 사용합니다.
- 클릭으로 위치를 고르고, 끌기·방향키·확대 버튼으로 지도를 살펴봅니다. 지도에 키보드 포커스를 두고 Enter/Space를 누르면 화면 중심을 선택합니다.
- **이 좌표를 입력에 반영**한 뒤 실제 현장과 대조해 기존 **현장 좌표 확인 완료**를 누릅니다. 좌표 변경은 이전 기상 확인·승인을 무효화하지만 수색 지도·격자·기체·탐지 사진의 위치는 바꾸지 않습니다.
- 단순히 외부 구글 지도 페이지를 여는 방식과 좌표 자동 반영은 다릅니다. 자동 반영은 기존 공식 지도 연결을 이용하며, 키 없는 환경에서는 좌표 붙여넣기를 사용합니다. 외부 페이지의 내용을 자동 수집하지 않습니다.

## 지도 준비와 사각·회전 격자

수색 지도의 첫 준비 도구에서 사진 선택, 캡처 붙여넣기, 온라인 지도 또는 지역 지도 저장을 고릅니다. 캡처는 **지도 캡처 붙여넣기**를 누른 뒤 Ctrl+V 또는 ⌘V를 사용합니다. 클립보드를 자동으로 읽지 않습니다. 기존 이미지 드래그앤드롭·좌표 파일·지역 지도 백업 불러오기는 유지합니다.

1. **격자·자유 구역 설정 → 사각 수색영역 드래그**를 누릅니다.
2. 지도에서 실제로 사용할 영역을 끕니다. 지도 안의 적용·수정·취소 도구를 사용합니다.
3. **위치·이름 수정**에서 중심·가로·세로 비율과 회전 각도를 조절합니다. 지도 밖으로 나가는 격자는 저장하지 않습니다. 행·열은 기존 지도·격자 설정에서 1~12로 정합니다.
4. **격자 적용**을 누르고 확인합니다. 변경 전 격자 상태·담당·좌표·기체 담당구역·자유 구역은 이력에 남고, 변경한 격자는 새 세대로 시작합니다. 기존 지도·핀·탐지 사진과 활동기록을 유지합니다.

격자 회전은 사진 자체의 지리좌표 보정을 대신하지 않습니다. 사진 좌표 보정은 정북 방향의 자료를 기준으로 확인하고, 회전된 캡처의 정확한 GPS가 자동으로 생긴 것으로 판단하지 않습니다. 새 격자에서는 중심 좌표와 탐지 사진의 격자 위치를 같은 변환으로 계산하며, 격자 밖 촬영 위치도 별도로 표시합니다.

## 도로·능선을 따르는 자유 구역

- 이름·상태·담당을 입력하고 **지도에서 구역 그리기·꼭짓점 편집**을 선택합니다.
- 클릭으로 3~32개의 점을 찍습니다. 선이 교차하거나 면적이 너무 작으면 저장하지 않습니다. 원형 꼭짓점을 끌어 위치를 수정하고, 지도 안의 **점 취소**로 마지막 점을 되돌립니다.
- 키보드 입력 영역에서는 번호별 꼭짓점 이동·뒤에 삽입·삭제도 가능합니다. 저장하기 전 초안은 현재 기록을 바꾸지 않습니다.
- **구역 저장** 후에는 선택 목록에서 해당 구역의 상태·담당을 반영합니다. 상태 변경은 이전·변경 후 값을 활동기록에 남깁니다. 꼭짓점 변경·삭제는 변경 전 이력을 남깁니다.
- 자유 구역은 기존 A1 격자와 별도 기록입니다. 완료를 자동 전파하지 않으며 현황에서도 별도 개수로 집계합니다. 표시 설정에서 격자와 자유 구역을 각각 숨겨 볼 수 있습니다.
- 상황당 자유 구역은 24개, 변경 전 구역 이력은 20개입니다. 한도에 도달하면 자동 삭제 대신 백업 후 새 수색으로 분리하도록 안내합니다.

## 백업·복원과 검증 범위

새 JSON에는 회전·영역·이전 구역의 지도 본체도 포함합니다. 이전 지도를 읽지 못하거나 24 MiB를 넘으면 완전한 백업으로 표시하지 않습니다. 읽는 중이면 다시 시도하고, 누락 시 원본 백업을 확인합니다. 상태 저장·백업 적용 실패에서는 기존 상황을 유지하며, 다른 작업·완전 삭제 뒤 늦은 작업이 자료를 되살리지 않도록 기존 세대·파일 작업 검사를 적용합니다.

재실행: `node tests/field-geometry.mjs`, `node tests/field-workflow-browser.mjs --modules /absolute/node_modules`, `node tests/run-regression-browser.mjs --modules /absolute/node_modules`. 결과·화면은 커밋에서 제외한 `output/playwright/`에 생성합니다.

검증은 임시 Chrome 저장영역·가상 지도·가상 상황으로 수행합니다. 구글 좌표 선택의 연결·클릭·반영은 모의 SDK로 검사하고, 기존 Google/Naver SDK 계약과 실제 MapLibre·오프라인 재시작은 별도 실행합니다. 실제 구글 API 키 사용·과금, 기관망·물리 휴대폰·Windows 장비 인수시험을 완료했다고 표현하지 않습니다.

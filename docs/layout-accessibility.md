# 노트북 배치와 모바일 우선 지시 접근성

2026-10-19 · 운영판 반영 범위와 검증 기록.

## 기준과 반영 결정

사용자가 승인한 OpenDesign STAY UP 보완 시안(2026-10-19)의 노트북 한 화면 배치와 모바일 상단 지시 방식을 기존 운영판에 반영했습니다. 새 가상 데이터 앱으로 교체하지 않고, 운영판의 기존 HTML·동기화·기록 기능에 표시 방식을 적용했습니다. 기존 STAY UP의 색상 역할과 네이티브 조작 도구를 유지했습니다.

| 결정 | 근거 | 운영판 적용 |
| --- | --- | --- |
| 노트북의 지도·우선 지시를 함께 표시 | 승인된 1366×768·1280×720 보완 시안 | 짧은 PC 화면에서는 여백·요약을 조정하고 좌우 상세를 내부 스크롤로 표시 |
| 중요한 명령을 문장 전체로 표시 | 승인된 모바일 우선 지시 카드 | 기존 `mission.priorityOrder`의 최대 80자 명령을 조작·기본·원거리에서 고정 표시 |
| 긴 원문은 별도로 읽기 | 기존 운영판의 `mission.orders`와 승인된 상세 펼침 | 원문과 TRS·호출부호·브리핑을 상세에 표시; 원문을 자동 요약하거나 잘라 명령으로 바꾸지 않음 |
| 모바일 시각·문서 읽기 순서를 일치 | 승인된 단일 지시 요소 재배치 | 표출 화면에서는 같은 지시 요소를 헤더 뒤로 이동, PC에서는 원위치 복원 |
| 판정과 조작 접근성 보존 | 기존 안전 판정·모바일 탐색과 Refero focus/touch 지침 | 모바일 조작 화면의 지시·판정을 함께 고정, 44px 상세 버튼·건너뛰기·제목 포커스 및 스크롤 여백 |

우선 지시가 비어 있고 전문이 80자 이내이면 기존 전문을 그대로 보여줍니다. 전문이 더 길면 우선 지시 미입력임을 표시하고 상세로 안내합니다. 새 지시를 추론하거나 작성하지 않습니다. 전문은 상세의 스크롤 영역에서 전부 읽을 수 있습니다.

## 기능·기록 보존

- 상태 버전·localStorage 키·IndexedDB·백업 형식·지도 좌표계·기체 상태·안전 판정 계산을 변경하지 않습니다.
- AI 후보 수동 불러오기, 같은 PC 자동 폴더 읽기, 원본 중복 갱신, 대응 메모·이력과 원본 판정 분리를 유지합니다.
- 상세 펼침과 화면 크기 변경은 해당 창의 임시 보기 상태입니다. 저장 리비전·활동 이벤트를 만들지 않습니다.
- 지휘부 지시 전문, 인원 상세, 기체 상세와 활동 타임라인은 삭제하지 않습니다. 노트북 좌우 영역을 Tab으로 선택해 키보드로 스크롤할 수 있습니다.
- 조작 패널은 입력 항목이 많으므로 기존 문서 스크롤과 섹션 이동을 유지합니다. 노트북에서 한 화면에 맞추는 대상은 표출 화면입니다.
- PC 창의 본문 높이가 700px 미만이면 내용을 자르는 대신 문서 스크롤을 허용합니다. 700px 이상에서는 낮은 화면용 배치를 사용합니다.
- 경보음 준비 버튼을 시계 영역에 배치해 우선 지시와 상세 버튼을 가리지 않도록 했습니다. 기존 경보음 준비·발견·유인기 경보 동작은 유지합니다.
- 승인 정책·외부 서비스 연결·저장 정책을 추가하거나 변경하지 않습니다.

## 검증 재실행

프로젝트 외부의 Playwright 설치 경로를 전달하거나, 프로젝트에 설치된 Playwright를 사용합니다.

```sh
node tests/layout-browser.mjs --modules /absolute/node_modules
```

구버전 HTML을 별도 보관해 두었다면 `--before /path/to/previous/stayup-dash.html`을 함께 지정합니다. 같은 격리된 Chrome 저장영역에서 구버전으로 가상 상황·후보·대응 기록을 저장하고 신버전으로 다시 열어 비교합니다. 사용자 브라우저 프로필이나 실제 출동 기록은 사용하지 않습니다.

검사 내용: PC 1920×1080·1440×900·1366×768·1280×720의 기본/원거리 표출, 모바일 390×844·360×800의 조작/표출, 두 창 지시 동기화, 상세 열기·키보드 접근·스크롤 후 유지, 메모 초안·기존 기록 보존, 실제 JSON 다운로드·재시작, 기존 전체 브라우저 회귀 검사.

결과 JSON과 화면은 커밋에서 제외한 `output/playwright/layout/`에 생성됩니다. 실제 결과와 배포 버전은 README의 이번 업데이트에 기록합니다. 모바일 화면 크기는 Chrome에서 검증하며 물리 휴대폰·현장 장비 인수시험은 별도입니다.

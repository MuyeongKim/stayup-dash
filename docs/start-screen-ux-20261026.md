# 시작 화면을 행동 중심으로 정리

## 기준과 범위

- 대상: 프로그램 구조를 모르는 첫 사용자. 처음에는 시작할 행동을 고르고, 시작 후에는 기존 준비 순서로 입력한다.
- 기준 화면: v1.2.40의 실제 빈 화면과 사용자가 승인한 밝은 배경·파란 선택 메뉴·주황 주요 버튼. 색상·경보·상태 의미를 유지한다.
- Refero 도구가 없어 `refero-design`의 copywriting 지침(현재 맥락·상태·다음 행동, 빈 화면의 첫 행동)과 기존 프로그램을 참고한다. 새 시각 체계나 이미지 자산을 만들지 않는다.
- 빈 작업의 시작 선택과 실제 입력 화면을 보기 상태로 구분한다. 기존 상황은 바로 이어서 열며 저장 형식·업무 값·안전 판정·확인 절차는 유지한다.

| 상태 / 조작 | 확인할 결과 |
| --- | --- |
| 빈 첫 실행, PC·390px·320px | 새 수색 준비·백업 열기·연습하기가 먼저 보임. 미입력 현황·전체 메뉴·입력칸으로 시선이 분산되지 않음 |
| 새 수색 준비 | 상황 입력과 기존 메뉴·안전 판정·경보가 나타나고 첫 입력에 초점 연결 |
| 준비 단계 이동 | 현재 입력 영역만 보임. 통신·지도·자동 백업 등 필요한 설정은 해당 단계에 남음 |
| 파일 열기 취소 / 잘못된 파일 | 시작 선택 또는 명확한 오류·재시도 경로에 접근. 업무 값 보존 |
| 정상 파일 열기 / 기존 작업 재시작 | 사진·인원·기체·구역·기록 보존. 저장된 작업을 숨기거나 새 상황으로 바꾸지 않음 |
| 연습 선택 / 돌아오기 | 실제와 연습의 상태·사진·지도·표출 분리 유지 |
| 보기 전용·저장 실패·유인기 경보 | 시작 화면 단순화로 잠금·저장 오류·실제 경보를 가리지 않음 |
| 준비→기록→백업→다시 열기 | 실제 가상 파일을 내려받고 업무 값·사진·기록 비교 |
| 메뉴·펼침·테마 왕복 | 업무 자료·작성 중 메모·리비전을 바꾸지 않음 |

도구 기반의 실제 Chrome 실행 검토이며, 실제 초보 직원 관찰 평가나 물리 장비 시험으로 표현하지 않는다. 출동 자료·기존 사용자 브라우저 프로필은 사용하지 않는다.

## 적용과 확인 결과

- 빈 시작 화면은 세 가지 시작 선택만 먼저 보여 준다. 입력을 시작한 뒤에는 기존 메뉴·안전 판정·지시·경보와 선택한 입력 영역이 나타난다. 저장된 상황은 기존 기록 화면에서 바로 이어서 열린다.
- 각 시작 선택 아래에 하는 일을 한 문장으로 설명했다. 보기 전용의 잠금 안내·입력권 전환과 저장 실패 표시는 시작 화면에서도 남긴다. 유인기 경보가 있으면 빈 작업이어도 입력·경보 화면을 숨기지 않는다.
- 상황의 통신 상세·지도 세부 설정은 기존 메뉴에 유지했다. 전체 입력 확인은 안전·백업 단계에서, 자동 백업 시점·파일 설정은 백업 단계에서 확인한다.
- 시작 화면의 파일 선택 취소·다른 종류 파일 거부는 시작 선택을 유지한다. 정상 백업은 입력 화면으로 연결되며 원래 자료를 복원한다.
- 임시 브라우저에서 실제 화면을 클릭·입력하며 상황→대상자→인원→드론→가상 사진→안전 미확인→기록→백업을 수행했다. 내려받은 전체 파일과 원래 값을 비교하고, 다른 빈 프로필의 시작 화면에서 같은 파일을 열어 사진·입력·기록 보존을 확인했다.
- 기존 가져오기가 갱신하는 메타정보·지도 ID·지도 버전은 업무 자료와 구분했다. 빈 연령의 기존 재시작 정규화도 유지했다. 저장 형식·상태 버전·실제/연습 분리·안전 판단은 바꾸지 않았다.

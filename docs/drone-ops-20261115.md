# 드론 운용·관제 상황판 5회 반복 보완 (2026-11-15)

요청: "드론 운용 및 관제 상황판으로서, 사용자(기록자) 입장의 사용 편의성과 이것을 보는 사람(지휘관) 입장의 직관성을 중심으로 로직 개선·꾸밈 개선안을 도출하고, 검증과 보완 도출을 5회 반복."

각 회차는 **평가 → 개선 → 실제 화면에서 검증 → 검증 중 찾은 보완**의 순서로 진행했습니다. 수치는 Chrome에서 연습 자료로 직접 잰 값입니다.

## 남은 것

- 남은 비행 계산은 배터리 100%→25%를 항속시간 동안 고르게 쓴다는 어림입니다. 바람·고도·센서 사용에 따른 차이는 반영하지 않습니다. 실제 잔량을 확인해 넣으면 그때부터 다시 계산합니다.
- 기체 위치는 담당구역 칸 또는 사람이 놓은 표식입니다. 실시간 GPS 위치가 아닙니다.
- 1366×768 벽 화면 지도는 22% 수준입니다.

## 검증

- 전체 Chrome 브라우저·엔진 검사 33개 파일과 회귀 411/411 통과(1.5배 문제를 고친 뒤 관련 6개 파일 재확인).
- 새 검사 [tests/drone-ops-browser.mjs](../tests/drone-ops-browser.mjs) **21/21**: 남은 비행 감소·복귀 단계·재확인·땅 위 기체 제외, 위험 요약, 카드 배지·다음 복귀, 칸 표·표식 중복 제거, 지금 확인 순서, 빠른 잔량 확인·교체 완료·범위 밖 값 거부, 기록 구역 중복 제거, 입력 화면 지금 확인, 경보 중 안전 띠, 상단 높이 고정, 지도 30% 이상.
- 실제 현장 지휘관·기록자 사용, 실제 기체 텔레메트리와의 비교는 하지 않았습니다.

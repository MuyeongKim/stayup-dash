## 남겨 둔 것

- 판정 등급: 비행 중 기체 하나의 조종자 문제도 상단 판정을 `비행 불가`로 만듭니다. 검토자는 기체 하나의 문제는 `조건부`로 낮추자고 했지만, 안전 판정 규칙을 바꾸는 일이라 지휘관 판단이 필요해 그대로 두고 문구만 `조종자 확인 필요`로 맞췄습니다.
- 상단 `15:39 남음`처럼 단위 없는 시간 표기, 비행시간 `22:51`(분:초), 근무시간 `6:10` — 표기 전체를 바꾸는 일이라 기존 화면 검사와 함께 따로 정리할 일입니다.
- 위험 기체 카드를 쪽 넘김에서 빼 고정하는 것, 입력 화면 첫 탭·휴대폰 발생시각 칸 위치(기존 설계), 우선 지시의 발령 시각(저장하는 항목이 없음), `감지기 없음` 문구, `계수`·`원본 31%` 같은 전문 표기.
- 휴대폰 가로 화면(높이 360px 안팎)에서는 빨간 위험 한 줄이 숨습니다. 기록자는 세로로 쓰는 것을 권합니다.
- 특이사항의 구역 칸은 격자 밖 이름도 받습니다(장소 메모로도 쓰므로).
- 남은 비행·교체 없이 대기 잔량은 배터리를 항속시간 동안 고르게 쓴다는 어림입니다. 실제 잔량을 넣으면 그때부터 다시 계산합니다.
- 1366×768 벽 화면에서 기체가 많으면 기체 카드 영역은 150px 안팎입니다. 그 대신 `기체 한눈에`에 모든 기체가 보입니다.

지도는 실제 완주군 지형이며 실종자·기체·인원·핀·구역·활동기록은 모두 가상 시연 데이터입니다.
실제 출동 사례나 수색 실적이 아닙니다. 지리좌표 보정은 하지 않았고,
화면의 지도폭·추정반경·배터리·기상·판정 수치는 샘플 입력과 그 계산 결과입니다.
실측값·실시간 관제정보·GPS 정확도 검증으로 해석하지 않습니다.

별도 검토 기록에는 PC 확대·이동 시 기록 불변, 핀의 원본 이미지 위치 유지,
칠하기·되돌리기, 같은 브라우저 두 창 동기화가 확인돼 있습니다.
촬영본을 처음 문서에 반영한 단계에서는 앱 코드를 수정하거나 전체 회귀검사를 다시 수행하지 않았습니다.

v1.2.4 촬영 당시 390px 휴대 화면에서 핀 라벨 약 2.93px, 점 약 3.41px 문제가 확인됐습니다.
이는 개선 전 기록입니다. 이후 모바일 지도와 큰 지도의 표시 CSS를 보완해
라벨 글자 최소 13px·점 최소 14px를 기본·큰 글자 표시 모두에서 유지하도록 했습니다.
핀 배치·좌표 저장 로직과 이 문서의 PC 촬영본은 바꾸지 않았습니다.
실제 현장·물리 터치 장비·GPS 좌표 정확도 및 장비별 시청거리 검증은 별도 인수시험 대상입니다.
